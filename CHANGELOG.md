
# Changelog

All notable changes to Arcade Core will be documented here.

## [1.0.1] - 2026-11-02

### Changed
- Added validation for movement directions.
- Invalid directions now throw a RangeError.

### Tests
- Added a test for invalid movement directions.
- All 5 automated tests pass.

## [1.0.0] - 2026-11-02

### Added
- Implemented move() for four directions.
- Implemented spawn() for random tile generation.
- Implemented canMove() to validate moves.
- Implemented hasMoves() to detect game over.
- Added automated tests using Node.js.
- Added README documentation.
